# NCFV 论文式（3-34）分方向归一化：实现与验证

日期：2026-09-07。

## 实现范围

NCFV 高效与传统模式均改用马润之硕士论文第 3.2.2 节式（3-34）：

\[
\Delta x_i=(x_{\max,i}-x_{\min,i})/2,\quad
\Delta y_i=(y_{\max,i}-y_{\min,i})/2,\quad
\Delta z_i=(z_{\max,i}-z_{\min,i})/2.
\]

极值来自完整节点对偶控制体，而不是原始单元或重构模板包围盒。
初始化从微四面体的节点、边中点、面顶点坐标均值、体顶点坐标均值
累积相对节点的坐标极值，存储上下界与三个参考长度；不依赖 Gauss 点，
也不依赖 `retainMicroGeometry=true`。二维仅使用 x/y，z 尺度设为 1。
有效方向的零/非法跨度报错，不静默退回统一体积尺度。

普通节点的三个参考长度通过 owner/ghost 映射同步。全平移周期节点
按代表节点合并各份额的节点相对坐标上下界，再计算半跨度。
因此周期角点也使用完整控制体，跨域绝对坐标不会错误放大跨度。
周期目录仍沿用 NCFV 已有的初始化 Allgatherv 实现，本次未改为可扩展的分布式目录。

设 H_i=diag(Δx_i,Δy_i,Δz_i)，所有基函数使用 ξ=H_i⁻¹(x−x_i)，
均值矩的一次项左乘 H_i⁻¹，二次矩使用 H_i⁻¹ M₂ H_i⁻¹，包含全部交叉项。
邻居均值基仍使用目标节点的参考坐标与尺度，再减去目标体均值。
完整二次问题求伪逆后，高效模式保存前三行，并以 H_i⁻¹ 还原物理梯度。
传统模式在通量/黏性积分点和限制器采样点使用同样的分方向尺度及链式求导。
纯二次项的 ξ²/2 系数约定保持不变。

`lengthScale=V^(1/d)` 仍用于原有距离权重和 CFL/壁面尺度，
不再参与重构基函数；本次不改变权重、模板目标、积分规则或 JSON 模式名称。
秩和条件数筛选仍作用于新的归一化矩阵。
现有 JSON 不必修改，两种算法都会自动使用论文尺度。
重启状态格式不变，初始化时重新生成参考长度。
没有修改 Geom、CFV、Euler、ACM 等其他模块。

## 回归测试

构建目标：`NCFV`、`ncfv_unit_tests`。
验证命令：`ctest --test-dir build -R '^ncfv_' --output-on-failure -j 2`。

7 个 CTest 注册项通过：几何单元测试、MPI 并行测试 np=1/2/4/8、I/O 测试 np=1/2。
新断言包含：

- 三个方向半跨度与二维退化方向处理；
- 各向异性零均值基与独立二阶精确单纯形积分的一致性；
- 非等长参考尺度下，基函数物理导数与差分对照；
- 原立方网格拉伸为 (0.05,2,5) 后，独立扫描微体顶点验证缓存跨度；
- 关闭微几何存储后，owner/ghost 参考长度仍完整；
- 两种模式重构独立积分的二次多项式均值，恢复节点值及物理梯度；
- 传统模式在 ghost 节点的非零偏移处评价二次多项式梯度；
- 周期面、边、角点及拉伸周期盒恢复完整半跨度；
- 周期初始化重复调用不累积旧矩或上下界；
- 原有均匀流、黏性、局部 CFL、周期输运守恒和重启/I/O 回归。

其中新增拉伸网格多项式测试只重构，不推进时间；原有周期守恒测试保留其两步推进。

## 结果解释

归一化已与论文一致，但不能保证每套网格的条件数都低于原统一尺度版本；
当前四套网格的新条件数为 2.72～4.11，仍远离病态。
当模板和权重固定、矩阵满列秩且没有奇异值截断时，改变基函数尺度只是
可逆列缩放，精确算术下不改变最小二乘得到的物理多项式。
本次物理量仅有舍入级变化、梯度阶数基本不变，符合这一性质。
不应据此声称 iv10→iv20→iv40 的低表观阶已经解决。
