## 计划：ODE 时间推进方法推导 PDF

### 目标
总结 `ODE.hpp` 中所有时间推进方法的数学推导，生成 PDF 文件。

### 涉及的方法
1. **隐式向后 Euler**（ImplicitEulerDualTimeStep）
2. **SDIRK**（ImplicitSDIRK4DualTimeStep，多种 Butcher 表）
3. **BDF**（ImplicitBDFDualTimeStep，k=1..4）
4. **可变步长 BDF**（ImplicitVBDFDualTimeStep）
5. **Hermite-3**（ImplicitHermite3SimpleJacobianDualStep）
6. **SSP-RK3**（ExplicitSSPRK3TimeStepAsImplicitDualTimeStep）

### 输出
- PDF 文件路径：`docs/readme/ODE_Time_Stepping_Methods.pdf`
- 内容：每种方法的数学公式、Butcher 表/系数、算法流程

### 实现方式
- 使用 ReportLab 生成中文 PDF（字体已验证可用）
- 包含数学公式（Unicode + HTML 实体）
- 包含 Butcher 表和系数表

### 需要用户确认
1. 目标文件夹路径是否为 `docs/readme/`？
2. 是否需要推导代码中的具体实现细节，还是仅数学公式？
3. PDF 语言：中文还是英文？
